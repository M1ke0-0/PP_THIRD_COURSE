# Разработка информационной системы для проведения онлайн-тестирования

Разработай полноценное учебное веб-приложение для проведения онлайн-тестирования студентов.

## 1. Цель проекта

Необходимо создать информационную систему, которая позволяет преподавателям создавать и управлять тестами, а студентам проходить тестирование и просматривать результаты.

Система должна поддерживать разграничение прав доступа для разных типов пользователей:

* **Администратор**
* **Преподаватель**
* **Студент**

Проект должен быть полностью реализован на Python и подходить для учебной демонстрации и защиты.

---

## 2. Технологический стек

Использовать следующий стек:

* Python 3.12+
* Django 5+
* SQLite для разработки
* PostgreSQL предусмотреть как возможность для дальнейшего развёртывания
* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Django ORM
* Django Authentication
* Chart.js для отображения статистики

Не использовать сложные внешние сервисы, если без них можно обойтись.

Главный приоритет — понятный, структурированный и легко объяснимый код.

# 8. Таймер

Для каждого теста существует ограничение времени.

Например:

```text
Продолжительность: 30 минут
```

После начала попытки запускается таймер.

Если время закончилось:

* тест автоматически завершается;
* ответы сохраняются;
* попытка получает статус EXPIRED;
* автоматически рассчитывается результат.

Важно сделать проверку времени также на сервере, а не только JavaScript-таймером.

---

# 9. Проверка результатов

После завершения теста система должна автоматически проверить ответы.

Для каждого вопроса:

* определить правильность ответа;
* начислить баллы;
* подсчитать количество правильных ответов;
* рассчитать процент.

Формула:

```text
Процент = (набранные баллы / максимальные баллы) × 100
```

Если результат >= проходного балла:

```text
Тест пройден
```

Иначе:

```text
Тест не пройден
```

# 28. Результат

В результате должен получиться полностью рабочий веб-сервис онлайн-тестирования, который можно запустить локально командой:

```bash
python manage.py runserver
```

Система должна позволять пройти полный сценарий:

```text
Администратор
      ↓
Создаёт пользователей
      ↓
Преподаватель
      ↓
Создаёт тест
      ↓
Добавляет вопросы
      ↓
Назначает тест группе
      ↓
Студент
      ↓
Входит в систему
      ↓
Видит доступный тест
      ↓
Начинает прохождение
      ↓
Отвечает на вопросы
      ↓
Завершает тест
      ↓
Система автоматически проверяет ответы
      ↓
Формирует результат
      ↓
Результат попадает в статистику преподавателя
```

Проект должен быть ориентирован именно на учебные цели: архитектура и код должны быть достаточно простыми для понимания студентом, но функциональность должна выглядеть как полноценная информационная система.
